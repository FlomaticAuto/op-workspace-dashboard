How to use this report
Overview tab — YTD totals for both employers. Use the employer summary table to compare Olympic Paints vs Primeserve compliance.
Yesterday tab — Who missed their clock-out on the most recent working day. Action this list each morning.
Daily Attendance — Filter by date range to inspect any period. Use the chart to spot dips in headcount.
Departments — Which departments have the most missing clock-outs. Useful for line-manager conversations.
Weekly Hours — Per-employee hours in Wed–Tue weeks. Use the week chips to isolate recent weeks. Export to Excel for payroll.
Missing Clock Out — Full log of every missed punch. Search by name, ID, or department. Top-10 repeat offenders are charted.
How to process a new clocking export
  1. Export the transaction file from Advius biometrics (any date range). Save as Transaction*.xlsx.
  2. Drop the file into the Inbox folder.
  3. Run process_inbox.py — it calls build_report.py with the master flag, renames the output to Clocking Report YTD.xlsx, archives the input, and emails the result.
  4. Run gen_dashboard.py to regenerate this dashboard and push to GitHub Pages.
Rules: 45-minute break is deducted from every shift automatically. Employees with IDs starting with SD belong to Primeserve; all others are Olympic Paints. Never skip the --master flag.
