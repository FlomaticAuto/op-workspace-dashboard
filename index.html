Manual Executions

One-shot scripts that aren't on a schedule. Copy the prompt, paste it into a Claude Code session, and the agent will run the script for you. No local server required.

Runbooks

One runbook per automated system — purpose, schedule, inputs, failure modes, manual run, recent incidents. Tap a card to read the full procedure. Drift status is checked against current git state every time this page is built.

Kaizen

Weekly improvement triage. weekly_kaizen.py writes friction signals into each agent's ## Accumulated Learnings. /kaizen on Mondays promotes them to Notion tasks. Move a task to Kaizen Status = Implement in Notion to trigger the agent edit (poller runs Wed & Sun 12:00).
