Forms Admin — Internal Form Management

Two-repo system for building, publishing, and reviewing internal web forms without JotForm dependency. A public-facing form renderer hosted on GitHub Pages collects submissions into Supabase; a password-protected Next.js admin panel lets staff view responses and export CSV.

● Built 11 May 2026 Supabase + Next.js 15 GitHub Pages · Vercel
🌐
REPO 1 — Public Form Renderer
flomaticauto/olympic-paints-forms → GitHub Pages
📄
index.html
Single self-contained file. Reads ?form_id= from URL, fetches active form schema from Supabase anon key, renders fields dynamically, and POSTs submissions back.
🔒
Security model
Supabase anon key is public but safe — RLS restricts it to SELECT active forms + INSERT submissions only. No admin data is reachable from the browser.
🔗
Share a form
Copy the GitHub Pages URL and append ?form_id=<uuid>. Anyone with the link can submit. Expired forms return a friendly closed-form message.
🛡️
REPO 2 — Admin Panel
flomaticauto/olympic-paints-forms-admin → Vercel
🔑
Password-protected
Edge middleware checks oly_admin_auth httpOnly cookie. Login via ADMIN_SECRET env var set in Vercel — never touches the browser.
📊
Submissions table
Per-form view with all responses in a sortable table. Column headers derived from the form schema field labels in order.
⬇️
CSV export
Client-side Blob export — all submissions for a form download instantly with no server round-trip. Filename includes form title and date.
Supabase Backend
🗂️
form_schemas table
Stores form definitions: title, description, JSONB schema (field array), active_from / active_until dates, created_by.
📥
form_submissions table
Stores each submission: form_id FK, submitted_by (optional), JSONB data keyed by field ID, submitted_at timestamp, metadata.
🛡️
Row Level Security
Anon role: SELECT active forms only, INSERT submissions only. Service role (server-side admin): full access. No public reads on submissions.
⏱️
archive_expired_forms()
SQL function that sets is_active=false on forms where active_until < NOW(). Run manually or on a schedule — pg_cron not available on Supabase free tier.
