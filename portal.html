KPI Agreement Framework — Categories A–F
CatNameWeightTarget / Scoring MethodData SourceScope
A Revenue vs Monthly Target 40% Graded: actual ÷ monthly target. 100% = full 40 points QuickSight PDF → manual entry Main KPI · Per-rep
B Discount Management (Rock Bottom) 20% RB bands: (15%→20pts) (14%→16pts) (13%→12pts) (12%→8pts) (11%→4pts). % of lines below rock-bottom price per band Sales_Invoices_All.parquet Main KPI · Per-rep
C Debtors Management 15% Based on account current status — days overdue, balance proportion Pad/debtors_age_analysis.csv Main KPI · Per-rep
D New Store Account Acquisition 10% Graded: verified new stores ÷ quarterly target New Stores Added By Reps_*.xlsx (manual) Main KPI · Per-rep
E Merchandising (main dashboard) 10% Graded: min(visits ÷ 15, 1.0) × 10%. Scored on last completed month with auto-fallback to most recent month with data. Scored rep column shows e.g. "✗ 33% · 5/15" Meetings_Report_AWS_Merchandising.xlsx Main KPI only
F Merchandising (per-rep dashboards) 10% Graded: min(visits ÷ 45, 1.0) × 10%. Quarterly target = 45 visits (15/month × 3). Rep name extracted via regex from Note Content field: WHO IS THE REP THAT SERVICES THE STORE Meetings_Report_AWS_Merchandising.xlsx Per-rep only

Training was previously part of the Training & Merchandising bucket (70/30 split). As of May 2026, training is excluded entirely from scoring — the full 10% weight goes to merchandising. The KPI category E/F was renamed from "Training & Merchandising" → "Merchandising". Pill colours: ≥100% green · 50–99% amber · <50% red.

Design System — HTML Standards
RuleStandard
FontsBarlow Condensed (display/headlines, weights 300–900) · Barlow (body/UI) · Always imported from Google Fonts
Themes4-theme toggle required on every HTML file: Light · Dark · Brand · Navy. Applied to <html> element. Default: theme-navy for this portal, all management-facing files. theme-dark for standard dashboards
ColoursNever hardcode hex in component CSS. Always use --color-* semantic token properties defined in the theme blocks
LogoOlympic Paints Logo Digital.jpg wrapped in border-radius:50%;overflow:hidden div. Never use old inline SVG badge. Min 28px size. Build scripts: shutil.copy2(LOGO_SRC, OUT_DIR / 'logo.jpg')
ChartsChart.js from cdnjs only when explicitly needed. Always include barLabels plugin. Use _lblMap.set() for all bar chart labels
FrameworksNever use Tailwind, Bootstrap, or any external CSS framework. Vanilla CSS + vanilla JS only
