Returns Manager
Interactive returns processing dashboard for Olympic Paints. Log, track, and manage customer product returns — capturing return reasons, quantities, customer details, and resolution status. Built on Streamlit for real-time data entry and reporting.
How to ingest a new scan
  1. Project folder: 1.Projects\Returns KPI System\
  2. Start the watcher once: double-click Start Returns Watcher.bat (keep the console open).
  3. Drop the scanned Truck Offload PDF into Inbox\.
  4. Watcher OCRs via Claude Opus, writes rows to Returns_Database.xlsx, moves the PDF to Inbox\Archived\ on success (or Inbox\Failed\ on error), and pings Telegram with the result.
  5. Open the dashboard (Start Returns Dashboard.bat) to review / correct flagged rows.

Sales Reps PULSE

Daily push system for the 5 sales reps (AC, AP, BV, NP, BM). PULSE drives daily ack discipline, tracks plan vs actual against the 4-week customer cycle, escalates silence to Quintus, and publishes a live performance leaderboard plus a bi-weekly scorecard. Targets are computed each month as the prior-year same-month actual + 30%, NET of VAT.
