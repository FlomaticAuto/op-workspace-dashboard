## Source data

Only published source: **Golden Choice 2026.pdf** (pricelist) — 9 pages, no TDS data, no chemistry, no spreading rates, no solids %, no drying times. Only finish names, life-expectancy claims, colour ranges, pack sizes, prices.

⚠ **No TDS / MSDS PDFs available online.** Golden Choice does not publish technical datasheets. All chemistry inferences in the comparison workbook are flagged as `Not published (typical for tier)`.

## Why this matters competitively

Olympic's transparency advantage is at its strongest against Golden Choice. Olympic publishes solids %, viscosity (KU), SG, VOC class, exact drying times, application surfaces, and primer requirements on every TDS. Golden Choice publishes only the can label.
