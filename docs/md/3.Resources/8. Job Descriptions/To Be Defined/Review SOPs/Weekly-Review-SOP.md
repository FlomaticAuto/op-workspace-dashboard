# Weekly Review SOP
*Cadence: Every Friday (or Monday morning)*
*Time required: ~20 minutes*

---

## Purpose
Keep the system current. A weekly review prevents the Inbox from overflowing, catches stalled projects early, and ensures nothing falls through the cracks.

---

## Checklist

### 1. Empty the Inbox (`0.Inbox/`)
- [ ] Open `0.Inbox/`
- [ ] For each file: decide — Project, Area, Resource, or Archive?
- [ ] Move each file to the correct folder using the naming convention:
  `YYYY-MM-DD_Descriptive-Name_vN.ext`
- [ ] Inbox should be empty when done

### 2. Review Active Projects (`1.Projects/`)
- [ ] Open `1.Projects/INDEX.md`
- [ ] For each active project: is it still active? Any new files added this week?
- [ ] If a project is complete → move to `4.Archive/YYYY/ProjectName/` and update INDEX.md
- [ ] If a project is stalled → note why in the index

### 3. Check Areas for Loose Files (`2.Areas/`)
- [ ] Scan for any files sitting at the top level of an Area folder (not in a subfolder)
- [ ] File them into the correct subfolder or rename to match convention

### 4. Quick Scan of Resources (`3.Resources/`)
- [ ] Any new templates, SOPs, or reference docs to add?
- [ ] Any documents in `3.Resources/3.Meeting Minutes` that need filing?

### 5. Update Index Files (if anything changed)
- [ ] Update the relevant `INDEX.md` for any folders that changed this week
- [ ] Update the date at the top of any modified index file

---

## Done
The system is current. Inbox is empty. All new files are named and filed.
