# Monthly Review SOP
*Cadence: Last Friday of each month*
*Time required: ~45 minutes*

---

## Purpose
Zoom out from the weekly grind. Confirm the right work is being done, projects are progressing, and stale files are cleaned up. Update all index files to reflect the current state of the system.

---

## Checklist

### 1. Complete the Weekly Review First
- [ ] Run the full `Weekly-Review-SOP.md` checklist before continuing

### 2. Review All Active Projects (`1.Projects/INDEX.md`)
- [ ] For each project: has it progressed this month?
- [ ] If no activity in 30+ days: is it stalled or complete? Note it.
- [ ] If complete: archive it → `4.Archive/YYYY/ProjectName/`
- [ ] If stalled: identify the blocker and add a note to the index

### 3. Review the Archive (`4.Archive/`)
- [ ] Confirm archived projects are organised by year
- [ ] Delete any duplicate files in the archive (keep the latest version only)

### 4. Review Areas for Stale Content (`2.Areas/`)
- [ ] Open `2.Areas/INDEX.md`
- [ ] For each Area: any files older than 6 months with no activity?
  - If obsolete → delete or move to Archive
  - If still valid → leave it, note the last review date

### 5. Resources Health Check (`3.Resources/`)
- [ ] Are the SOPs still accurate? Flag any that need updating.
- [ ] Are there ad-hoc documents that should be promoted to a formal SOP?
- [ ] Check `3.Resources/4.Leads` — are leads still current or should they be purged?

### 6. Update All Index Files
- [ ] Update the date at the top of `INDEX.md` (root)
- [ ] Update `1.Projects/INDEX.md`, `2.Areas/INDEX.md`, `3.Resources/INDEX.md` as needed

### 7. File Count Sanity Check (optional)
- [ ] Note roughly how many files are in each top-level folder
- [ ] If any folder has grown significantly, investigate why and re-organise if needed

---

## Done
All indexes are current. No stale files. Archive is tidy. System is healthy for another month.
