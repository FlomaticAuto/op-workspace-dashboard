# Quarterly Review SOP
*Cadence: End of March, June, September, December*
*Time required: ~2 hours*

---

## Purpose
Big-picture system audit. Ensure PARA still reflects how the business actually works. Retire what's done, consolidate knowledge, and make deliberate decisions about what stays active.

---

## Checklist

### 1. Complete the Monthly Review First
- [ ] Run the full `Monthly-Review-SOP.md` checklist before continuing

### 2. Projects Deep-Dive (`1.Projects/`)
- [ ] List all active projects
- [ ] For each: is this still a *project* (has a finish line), or has it become an ongoing *area*?
  - If it's become an area → move it to `2.Areas/` and update both indexes
- [ ] Are there projects that should be started but aren't yet documented?
  - Create a folder in `1.Projects/` and add it to the index

### 3. Areas Deep-Dive (`2.Areas/`)
- [ ] For each area: is it still active? Is anyone responsible for it?
- [ ] Are there areas that are effectively done and should be archived?
- [ ] Are there new operational areas that need a folder?
- [ ] Check that each Area links correctly to its relevant Resources and SOPs in `2.Areas/INDEX.md`

### 4. Resources Deep-Dive (`3.Resources/`)
- [ ] Review all SOPs — are they still accurate and being followed?
- [ ] Are there undocumented processes that need a new SOP?
- [ ] Review `3.Resources/8.Job Descriptions` — are JDs still current?
- [ ] Review `3.Resources/6.Policies` — any policies that need updating?
- [ ] Templates audit: are the templates in `3.Resources/Templates/` being used?

### 5. Archive Audit (`4.Archive/`)
- [ ] Is everything in Archive properly organised by year?
- [ ] Are there files in Archive that could be permanently deleted?
- [ ] Is Old Folder still needed? If not, move anything worth keeping to Archive, then delete it.

### 6. Naming Convention Compliance Check
- [ ] Spot-check 20 recently created files
- [ ] Are they following `YYYY-MM-DD_Descriptive-Name_vN.ext`?
- [ ] If not, rename the ones that are actively referenced

### 7. Image & Asset Backlog (when ready)
- [ ] Review `3.Resources/9.Brand Assets & Images` for any organising that can be done
- [ ] Note: full image DAM implementation is on hold — this is a lightweight check only

### 8. System Reflection
Answer these 3 questions to complete the review:
1. What's working well in how the system is organised?
2. What's causing friction or confusion?
3. What one structural change would most improve the system next quarter?

Document answers in `3.Resources/3.Meeting Minutes/YYYY-MM-DD_Quarterly-Review-Notes.md`.

---

## Done
System is audited, aligned to current business reality, and set up for the next quarter.
