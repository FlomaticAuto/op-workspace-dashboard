# ⚠️ DEPRECATED — Weekly KPI Dashboard

**Deprecated:** 2026-05-25  
**Decision owner:** Quintus Lategan

---

This folder and its associated script (`build_kpi_dashboard.py`) are no longer maintained.

The weekly KPI dashboard workflow has been discontinued. The GitHub Pages site
(`https://flomaticauto.github.io/olympic-paints-kpi/`) is no longer active.

## What was here

- `build_kpi_dashboard.py` — manually maintained Python script that built a weekly HTML KPI
  dashboard from QuickSight PDF exports. Data was hand-entered each week.
- `index.html` — last generated dashboard output (week ending ~21 May 2026).
- `1.Projects/KPI Report/Weekly Progress/` — archived QuickSight PDF exports.

## Why deprecated

The manual data-entry workflow (read PDF → type numbers into script → run → push) was not
sustainable. KPI reporting has been superseded by other tooling.

## Data preserved

Raw data files, CSVs, and archives are retained in this folder for reference.
Do not delete without confirming data is available elsewhere.
