# Olympic Paints — Master Index
*Last updated: 2026-03-26*

## How This System Works

This folder uses the **PARA method**:
- **0.Inbox** — Drop anything new here. Review and file weekly.
- **1.Projects** — Discrete initiatives with a finish line.
- **2.Areas** — Ongoing operational domains with no end date.
- **3.Resources** — Reference material and templates.
- **4.Archive** — Completed projects and retired areas.
- **Old Folder** — Legacy content retained for reference only. Do not add new files here.

## Naming Convention (apply to all new files)
```
YYYY-MM-DD_Descriptive-Name_vN.ext
```
Examples:
- `2026-03-26_Pricing-Strategy_v2.xlsx`
- `2026-03-26_Aurik-Session3-Notes.docx`
- `DRAFT_2026-03-26_Sales-SOP.docx`
- `FINAL_2026-03-26_HR-Policy.pdf`

Do **not** rename existing historical files — apply this convention to new files only.

## Review Cadence
| Cadence | Action | SOP |
|---------|--------|-----|
| Weekly | Empty Inbox, file loose items, check active projects | `3.Resources/5.SOP/Weekly-Review-SOP.md` |
| Monthly | Update indexes, archive completed projects, purge stale files | `3.Resources/5.SOP/Monthly-Review-SOP.md` |
| Quarterly | Audit Areas, promote ad-hoc docs to formal SOPs | `3.Resources/5.SOP/Quarterly-Review-SOP.md` |
